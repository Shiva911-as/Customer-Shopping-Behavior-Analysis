# Customer Shopping Behavior Analysis

##  Project Overview

This is an end-to-end Data Analytics project based on customer shopping behavior and retail sales data.

The project uses **Python, SQL, and Power BI** to clean the data, analyze customer behavior, answer business questions, and create an interactive dashboard.

The main goal is to turn raw customer shopping data into useful business insights.

##  Business Problem

A retail company wants to better understand its customers and purchasing patterns.

The analysis focuses on questions such as:

* Which customer groups generate the most sales?
* Which products are most popular?
* How do customers shop across different categories?
* Does customer age or gender affect purchasing behavior?
* Which customers are more likely to be loyal or repeat buyers?
* What factors influence customer purchases?

---

## Dataset

The project uses a **Customer Shopping Behavior** dataset containing information about customer purchases.

The dataset includes fields related to:

* Customer demographics
* Product categories
* Purchase amount
* Discounts
* Reviews
* Shipping information
* Subscription status
* Payment methods
* Purchase frequency

##  1. Data Analysis Using Python

Python was used for the initial analysis of the dataset.

### Main steps:

* Import the dataset
* Understand the structure of the data
* Check missing values
* Check duplicate records
* Analyze data types
* Clean and transform the data
* Perform Exploratory Data Analysis (EDA)
* Identify important patterns and trends

Pandas was mainly used for data manipulation and analysis.

---

##  2. SQL Analysis

After preparing the dataset, SQL was used to answer business-related questions.

The SQL analysis includes:

* Customer segmentation
* Product analysis
* Purchase behavior analysis
* Sales analysis
* Customer loyalty analysis
* Discount and purchase analysis
* Aggregations and comparisons

SQL helped convert the cleaned data into meaningful business information.

---

##  3. Power BI Dashboard

Power BI was used to create an interactive dashboard from the analyzed data.

### Dashboard includes:

* Total customers
* Total sales
* Average purchase amount
* Customer segmentation
* Product/category performance
* Purchase trends
* Customer demographics
* Payment and subscription analysis

Interactive filters and visualizations make it easier to explore the data and identify important trends.
